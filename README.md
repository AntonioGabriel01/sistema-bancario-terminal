# Sistema Bancário Terminal

Mini sistema bancário desenvolvido em Node.js utilizando Inquirer, Chalk e persistência de dados em arquivos JSON.

## Funcionalidades

- Criar conta
- Consultar saldo
- Depositar dinheiro
- Sacar dinheiro
- Persistência dos dados em JSON

## Tecnologias

- Node.js
- Inquirer
- Chalk
- File System (fs)

## Instalação

```bash
npm install
npm start
